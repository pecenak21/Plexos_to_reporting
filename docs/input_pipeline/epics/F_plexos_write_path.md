## EPIC F — PLEXOS write path

**Component C4.** Phase 5–6. The foundation this epic rests on, traced record-by-record against APS's real model: **a property does not hold a value directly.** Time-varying data reaches PLEXOS through a Data File — a CSV on disk, plus a Data File object inside the model that points at it, plus a link from the target property to that Data File object. Writing data is therefore always two operations.

Sprint 6 in particular is where the **[LATE]** scenario decisions live. They are not in the technical design doc yet; they are in the v4 deliverable and in this backlog.
