### DIFF-01 — `compare()` engine skeleton and folder→model resolution

**As** both entry points, **I want** one comparison function that takes two folder paths, **so that** neither wrapper special-cases the other.

**Type:** Story · **Size:** M · **Traces to:** §10, §10.1 · **Depends on:** CDM-01, CDM-02

**Spec**

```python
def compare(old_path: Path, new_path: Path,
            old_model: str | None = None,
            new_model: str | None = None) -> ComparisonResult
```

Resolution rules, applied per side:

- Each side is a **folder**, not a `.db` and not an `.xml`. Neither side has to be a run folder — the rule is "find the model in this folder", which an archived run and an ordinary working folder both satisfy. Given that APS's real working model does not live in a run folder, the working-folder case is likely the common one, not the exotic one.
- **Exactly one `.xml`** → use it.
- **More than one `.xml`** → use `old_model` / `new_model` if given; otherwise raise asking which. **No convention-based guess** — not newest, not largest, not name-matched. A silently wrong pick produces a confidently wrong report, which is worse than no report.
- **Zero `.xml`** → raise naming the folder.
- Both sides' `.db` are generated by `ensure_db(force=True)` every time (CDM-01). Never trust a `.db` found on disk.

`ComparisonResult` holds the four level results plus the two resolved model paths and the generation timestamp, and is the only thing RPT-* consumes.

**Acceptance criteria**

1. **Given** two folders each holding one `.xml`, **when** compared, **then** both `.db` are regenerated and a result returns.
2. **Given** a folder holding two `.xml` and no model name, **then** it raises listing both filenames.
3. **Given** a folder holding two `.xml` and the correct name supplied, **then** that model is used.
4. **Given** a folder holding a `.db` newer than its `.xml`, **then** the `.db` is regenerated anyway and the result reflects the `.xml`.
5. **Given** an old side that is an archived run and a new side that is a plain working folder, **then** the comparison runs — no run-folder structure is required of either side.
